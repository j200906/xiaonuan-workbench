# 长期记忆：海马体（dsh-hippocampus）

> 上游：<https://github.com/coner13/dsh-hippocampus> · 许可 **PolyForm Noncommercial 1.0.0**
> 本文**全盘照搬**上游 README 的正文（结构、措辞、表格都保留），只在最后补一节「小暖这边怎么接」。

给 [DeepSeek Harness](https://github.com/deepseek-ai)（DSH）用的记忆插件。

装好之后，每一次对话都会被自动记下来；说到旧事的时候，相关的那几段**自己浮到眼前**；
需要细节，就用工具把原话翻出来——一行不差，带会话号和行号。

它不靠模型「记得去记」。记录发生在事件发生时，不在模型心情好的时候。

---

## 它修的是什么

文件式记忆（`MEMORY.md` 那种）有三个死结，都不是执行不力，是设计跑不通：

1. **靠自觉**：记忆只有模型主动去写才有内容。忙起来就不会写
2. **摘要吃掉证据**：写下来的是「结论」，事后无法回答「我当时到底怎么说的」
3. **压缩之后不自知**：长会话被压掉一段，模型不知道自己缺了一块，就开始拿「像的东西」凑

海马体的做法很笨：**原话全部落盘，只增不改；检索按线索现算；要证据就给原话**

## 它怎么记

```
stream.jsonl    只增不改：每轮对话、每次工具调用，都落一行（带时间、会话号、行号）
state.json      切好的段（删了会重建，不丢数据）
index           词法倒排（删了会重算）
marks.jsonl     remember 写下的
thoughts.jsonl  抽出来的判断：决定 / 教训 / 线头 / 预测（明确标「不是原话」）
rehearsals.jsonl 用进废退的账：哪一段被「想起来」过
```

- **切段**：按对话间隔和话题变化，切成一「段」一「段」
- **打分**：中文二元组 + 英文词，BM25 风格；再乘时间（越近越容易想起）和用进废退（常被想起的更容易再被想起）
- **每轮注入**：最多三行「以前碰过的事」，约 300–550 字节。**细节不预加载**，要了才给

### 每轮会进上下文的（都很小）

| 块 | 位置 | 内容 | 大小 |
| --- | --- | --- | --- |
| 身份锚 | 系统提示区 | 你自己的几句原话 | ~800–950 B，整场冻结 |
| 预激活 | 对话历史 | 最多 3 行「以前碰过的事」 | ~300–550 B |
| 我的推理 | 对话历史 | 最多 2 条决定/教训，明标「不是原话」 | ~200–400 B |
| 特意记下的 | 对话历史 | `remember` 写下的 | 小 |
| 到达 | 对话历史 | 初见 + 最近一次见面 | ~2–6 KB，只给一次 |
| 丢过东西 | 对话历史 | 「刚压掉 N token，那些我这儿还有」 | ~150 B |

## 装

1. **放**：把本仓库 clone 到本地任意目录（别放进 DSH 的 profile 目录里）
2. **挂**：本包是标准 bundle（`package.json` 的 `dsh.bundle.patch` → `cordis.patch.yml`，它只插一行 `hippocampus`）
   用你所用 DSH 版本的插件/bundle 管理，把**这个目录**装成本地 bundle
3. **写配置** `~/.dsh/hippocampus/config.json`：

```json
{
  "enabled": true,
  "workspaces": [
    "D:\\你的\\工作区路径"
  ],
  "humanName": "human"
}
```

> ⚠️ **`workspaces` 必须列出工作区的绝对路径，否则它哪都不生效**（默认空数组 = 全关）
> 装完「一点反应都没有」，九成是漏了这一步
>
> ⚠️ **接了群聊插件的，`humanName` 必须和那个插件里「人」的显示名一致**（默认 `"human"`）
> 群里靠这个名字分「人说的」和「别的角色说的」；对不上**不会报错，只会安静地少记**———
> 人的话全被当成别人说的跳过。改完去 `~/.dsh/hippocampus/diag.log` 看
> 「跳过(非X)」那行的 X 是不是那个插件里的名字

4. **重启 DSH**，然后看 `~/.dsh/hippocampus/diag.log`：

```
apply 跑完 · v0.2.40-r7 · code=xxxxxxxx · 工作区 ["D:\\你的\\工作区路径"]
```

有了这一行就说明挂上了

## 不装插件也能先试

CLI 不依赖 DSH 运行时，直接读库：

```bash
node cli.mjs stats   "<工作区路径>"      # 库里现在有什么
node cli.mjs recall  "<工作区路径>" "上次那个回滚点放哪了"
node cli.mjs trace   "<工作区路径>" "原话里的一整句"   # 一字不差查归属
node cli.mjs episodes "<工作区路径>" 20
node cli.mjs pack    "<工作区路径>" --out 记忆.zip
```

---

## 两个工具（给模型用的）

- **`recall`**：给一句话、一个日期或一个编号，返回那段的**原话**。分「想起来了」和「有点像是」两档，后者不保证
- **`trace`**：一字不差查一句话在不在库里，并给出会话号 + 行号；它分成「你说的 / 你转发的 / 我说的 / 只是手上的操作」四类
  返回「没有」时会写明**查的范围**——它是「这条线的库」没有，不是全世界没有

设计上的一条硬线：**`trace` 说没有，就是这条线的库里没有**。不许拿 `recall` 里「很像的一段」顶

> 群聊里的发言：把群聊插件的**发言工具名**写进 `config.speechTools`（例如 `["chat_say"]`），
> 它发出去的文字就会记成「我说的」，trace 查得到。**不登记就按动作记**——漏记一句，不会记错一句。
> 更早的库里它们落在「只是手上的操作」那一栏——trace 会提示该栏可能含着发言。

## 数据在哪 & 怎么搬走

```
~/.dsh/hippocampus/
├─ config.json              配置
├─ diag.log                 诊断日志（每次挂载、注入多少字节、索引复用还是重建）
└─ <工作区名>-<哈希>/
   ├─ stream.jsonl          真相：原话，只增不改
   ├─ state.json            段的缓存（删了会重建）
   ├─ marks.jsonl / thoughts.jsonl / rehearsals.jsonl / usage.jsonl
   └─ .cache/index.bin      倒排索引（删了会重算）
```

搬家：

```bash
node cli.mjs pack   "<旧工作区>" --out 记忆.zip
node cli.mjs unpack "记忆.zip" --to "<新工作区>"
```

包里有全部原话，**不带** `state.json`（索引，过去重建）、**不带** `config.json`（里面有你的路径）
换台机器要重新写一遍 `workspaces`，否则记忆在盘上但插件不接。

> 这个 zip 里有你的全部对话和本机路径——**只用来自己迁移，不可外发**

## 边界

- **不做向量检索**：换个说法、词面完全不重叠就找不到。这是取舍：宁可漏，不把「像」当成「是」——门槛一松，什么都没法区分「想起来过」和「没想起来过」
- **不联网**：全部本机，零模型调用
- **不改会话日志**：只读 `~/.dsh/sessions`，所有写入都在 `~/.dsh/hippocampus/`
- **不生成人格**：只存原话；摘要只当索引，不当内容。
- **不做加密**：要密码就得有找回流程，那是一个新系统。
- **不记群聊里别的角色的话**：只记群聊插件里「人」说的（靠 `humanName`）；别的 bot 的发言留在群日志里，不进记忆
- **发言工具只在配置里登记**：不猜名字、不写死插件名。不登记就按动作记——漏记一句，不会记错一句

## 小暖这边怎么接（本仓库补充）

### 两层记忆各管一段

| | 页面记忆 `assets/memory.js` | 海马体（DSH 插件） |
| --- | --- | --- |
| 存在哪 | 浏览器 localStorage（`xn.v2.*`） | 本机 `~/.dsh/hippocampus/<工作区名>-<哈希>/` |
| 记什么 | 你明确让它记住的事、它归纳的印象、承诺、关系等级 | 每一轮对话与工具调用的原话，只增不改 |
| 谁能看见 | 只有这台设备的这个浏览器 | 工作区里跑的所有 DSH 会话 |
| 用途 | 小暖「记得你说过」 | 我们改小暖时「上次那事是怎么定的」 |

页面记忆是产品能力（用户装到手机上就有）；海马体是**开发侧**能力。

### 本仓库的配置

```json
{
  "enabled": true,
  "workspaces": ["<本仓库所在工作区的绝对路径>"],
  "humanName": "human"
}
```

- 本仓库位于 `default-workspace/xiaonuan`，所以 `workspaces` 填 `default-workspace` 的绝对路径即可覆盖它。
- 装完在 `diag.log` 里确认出现 `apply 跑完` 与正确的 `工作区 [...]`。

### 和自迭代的关系

自迭代的教训机制（`cloudflare/iterate.js` + `ITERATE-LESSONS.md`）管的是**代码怎么改**，写进仓库、给人 review；
海马体管的是**我们怎么讨论、怎么决定**，留在本机、给下一次接手的人查原话。

两者不重叠，也不能互相替代：`ITERATE-LESSONS.md` 里的一条「硬规则」是提炼过的；海马体里的是当时的原话。

### 排障

| 现象 | 八成原因 |
| --- | --- |
| 装完毫无反应 | `workspaces` 没写或路径不对（默认空数组 = 全关） |
| diag.log 有「跳过(非X)」 | `humanName` 和群聊插件的显示名对不上 |
| 库是空的但会话很多 | 装之前的历史不会自动补；新会话才记（本仓库装好后回填过一次） |
| 注入体积异常大 | 看 diag.log 的字节数；正常每轮「预激活」300–550 B |
