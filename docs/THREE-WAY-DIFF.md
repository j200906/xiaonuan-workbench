## 三、v5.8 比 v4 多了什么（16 项）

| 新增 | 价值 |
|---|---|
| 情绪 LLM 二次判定 | 词表判不准时用模型复核 |
| 记忆复活 / 撤回遗忘 | 说错"忘掉"能撤回 |
| 记忆衰减与重要性 | 旧事会淡去，重要的留住 |
| 记忆巩固合并 | 定期把碎片记忆合成一条 |
| 冲突预算 | 防止反复调模型判冲突烧钱 |
| 特质互斥判定 | 不会同时"话多"和"沉默" |
| **目标推导 `derive_goal`** | 从对话里推出今天该做什么 |
| 关系简报 / 承诺简报 | 把关系进度和未兑现的承诺塞进 prompt |
| **中文引擎搜索** | 百度/搜狗/360，比 Bing 更能搜到中文 |
| 搜索限流与封禁检测 | 被封了会换引擎，不会一直撞墙 |
| 搜索结果缓存 | 同一问题不重复抓 |

| 仪表盘 / 快照同步 | 能看到系统在干嘛 |

## 四、网页版相对 v5.8 缺的 23 项，按严重程度分档

### 🔴 第一档：直接让聊天变差（用户天天会碰到）

| 缺什么 | 后果 |
|---|---|
| **上下文指代消解** | 问「杭州天气」→ 再问「那明天呢」，它不知道"明天"指天气，答非所问 |
| **记忆回溯 recall** | 用户说「上次那个项目」，它翻不出原话，只能说"我不记得" |
| **兜底：规则回复 + 情绪文案表** | 模型一挂就是一条红字错误，聊天直接断（v5.8 有 7×2 条本地文案能接住） |
| **IP 定位 + 天气专用接口** | 问天气没给城市，只能反问（v5.8 是自动定位直接答，体验差一个档） |
| **中文引擎搜索** | 只有 Bing/DDG，中文长尾内容搜不到 |

### 🟠 第二档：让它"活着"的部分

| 缺什么 | 后果 |
|---|---|
| **主动引擎（跟进/情绪回访/时间问候/配额）** | 从「它会想起你」退化成「你问我才答」 |
| **人格特质演化 + 互斥判定** | 永远只有出厂人设，聊多久都不变成"另一个它" |
| **目标推导 derive_goal** | 不会从对话里推出"你最近在准备考试" |

### 🟡 第三档：记忆与运维质量

| 缺什么 | 后果 |
|---|---|
| 记忆：衰减与重要性 | 所有记忆一律平等，旧事不会淡去 |
| 记忆：复活/撤回遗忘 | 说错"忘掉"就真没了 |
| 记忆：冲突判定 + 预算 | 新旧记忆矛盾时并存，模型自相矛盾 |
| 搜索：限流/封禁/缓存 | 容易被封，重复抓同一页 |
| 仪表盘 / 快照同步 | 看不见系统状态，出问题靠猜 |

## 五、网页版还多出来的（v5.8 没有的）

公平起见，网页也不是全输：

- 插件系统（注册/安装/回滚/DSH 兼容）
- 多端部署（本地 Python + Cloudflare Worker + 静态托管）
- 三语 i18n（235 键 × 3）
- 安全防护（SSRF 十项、CSP、插件地址策略、红队套件）
- 自迭代闭环（读反馈 → 模型出计划 → 自动提交）
- 自动化测试 145 项 + 冒烟 + UI + 红队

**这些是工程能力，v5.8 一个都没有。但 v5.8 有"灵魂"，网页有"骨架"。**

## 六、结论与建议

> **网页版实现了 v5.8 的 34.3%。丢掉的不是边角料，是聊天体验的核心。**

你之前抱怨的「发一条像发两条」「天气混城市」「人设吹牛」，本质都是同一件事：
**我们重建了一个壳，把 v5.8 里那些让对话顺滑的机制都丢了。**

建议按这个顺序补（前四项做完，聊天体验会有肉眼可见的提升）：

| 顺序 | 补什么 | 工作量 | 理由 |
|---|---|---|---|
| 1 | 兜底文案表 + 规则回复 | 半天 | 模型挂了也能接住话 |
| 2 | 上下文指代消解 | 2 天 | 「那明天呢」这类追问不再断片 |
| 3 | 记忆回溯 recall | 2 天 | 「上次那个事」能真的翻出来 |
| 4 | IP 定位 + 天气接口 | 1 天 | 天气不再反问，直接答 |
| 5 | 主动引擎 | 3–5 天 | 陪伴感的核心 |
| 6 | 特质演化 + 目标推导 | 3–5 天 | 让它"长大" |
| 7 | 中文引擎 + 限流缓存 | 2 天 | 搜得到中文内容 |
| 8 | 仪表盘 + 快照 | 1 天 | 运维可见 |

前四项合计约 **5.5 天**，就能把「用户天天碰到的卡点」补齐。
