# 与「小暖 v4 原版」的重合度比对

> 原版：`20261107-194049(1).py`（1266 行，小暖 v4 · 主动性 + 人格演化 + 对爱诚实的内核）
> 现状：`wt-ship` 仓库 v3.3.0（124 个源码/文档文件，JS + Python + Cloudflare 多端）
> 复跑：`node scripts/compare-origin.cjs <原版.py> .`

---

## 一、总体结论

| 维度 | 重合度 | 说明 |
|---|---:|---|
| **文本**（中文句子/提示词） | **27.3%** | 原版 128 句，现仓还能找到 35 句 |
| **能力**（机制/函数级） | **60.0%** | 20 项里 12 项有对应实现 |
| **代码行**（逐字相同） | **3.5%** | 888 行有效代码，仅 21 行逐字一致 |
| **加权合计** | **≈ 35.6%** | |

代码行重合低是**预期**的：原版是 Python 单文件，现在是 JS + 本地 Python 后端 + Cloudflare Worker 三端，语言和结构都换了。
真正该看的是**能力**和**文本**——这两项暴露了问题。

## 三、丢掉的（8 项，按严重程度排）

### 🔴 1. 主动性引擎 `ProactiveEngine`（原版 983–1130 行，约 150 行）

原版会**主动开口**，四种触发器：

- **跟进**：你上周提到「要考试」，过几天它主动问「考得怎么样」
- **情绪回访**：你上次情绪低落，6–48 小时后它来关心一句
- **时间问候**：早上/深夜按时间打招呼
- **配额与间隔**：`MIN_PROACTIVE_GAP_HOURS` / `MAX_PROACTIVE_PER_DAY`，不会骚扰

**现在完全没有。** 这大概是「陪伴感」最核心的东西——从「你问我才答」变成「我会想起你」。

### 🔴 2. 人格特质演化 `review_traits_batch`

原版会让 AI **自己长出观点和习惯**（最多 15 条，强度 ≥3 才生效），拼进 prompt 的
`【你自己的想法（你自己长出来的观点和习惯）】`。

**现在完全没有。** 现在的小暖永远只有出厂人设，聊多久都不会变成"另一个它"。

### 🟠 3. 跟进事项 `followups`

原版从对话里自动提取「值得过几天再问一句的事」，存库、到期触发。
**现在没有**（`followup` 关键词全仓 0 命中）。

### 🟠 4. 兜底回复 `FALLBACK` / `rule_reply`

原版有 7 种情绪 × 2–3 条本地文案，模型挂了也能回一句人话：
「我去，你要化身为化神境大能了？快去睡！」

**现在没有**：模型失败只会显示错误提示，聊天直接断掉。

### 🟠 5. 记忆冲突判定 `judge_conflict`

原版新记忆与旧记忆冲突时，会调一次模型判断哪条对（`CONFLICT_CHECK = True`）。
**现在没有**：冲突记忆会并存，模型可能自相矛盾。

### 🟡 6. IP 定位 `get_user_location`

原版用 `whois.pconline.com.cn` 查城市，**天气没给城市时自动定位**。
**现在没有**——上个月我们修的「天气混城市」问题，原版其实早就解了，而且解得更好：
原版是「自动定位后直接答」，我们改成了「反问用户城市」。

### 🟡 7. 专用天气接口

原版直连 `api.vvhan.com/api/weather?city=…`，返回结构化天气（天气/气温/风）。
**现在没有**：只能走通用搜索，然后把网页正文丢给模型自己提炼。

### 🟡 8. 后台线程 `start_daemon`

原版有常驻线程跑主动引擎计时。
现在没有对应物（Cloudflare 上要靠 Cron Trigger，还没接）。

## 四、文本层面丢了什么

原版 128 句中文，93 句找不到了。主要集中在：

- **主动性提示词**（「主动开口时额外注意」「关心要具体，不要空泛的」）——随引擎一起丢了
- **主动开场白话术**（「喂，昨天那个破事搞定没？」「哎嘿，我来查岗了！」）
- **兜底文案**（7 种情绪）
- **人格特质说明**（「想到的东西，但要说清来源」）

保住的 35 句主要是：人设核心（你是谁/性格比例/关于爱）、情绪提示、回复要求骨架。

## 五、我的判断

**重合度 35.6% 这个数字本身不丢人**——架构换代必然如此。真正要紧的是丢掉的东西里有三件是产品灵魂：

1. **主动性**（它会想起你）
2. **人格演化**（它会变成"另一个它"）
3. **兜底回复**（模型挂了也不冷场）

现在的版本是**更工程化的空壳**：有插件系统、有多端部署、有安全防护，但**少了那个"活着"的部分**。

### 建议补回顺序

| 优先级 | 事项 | 工作量 | 理由 |
|---|---|---|---|
| P0 | 兜底回复 `FALLBACK` | 小（半天） | 直接提升可用性，模型挂了不冷场 |
| P0 | IP 定位 + 天气接口 | 小（一天） | 把上个月那个"天气混城市"根治掉，而不是靠反问 |
| P1 | 主动性引擎（跟进 + 情绪回访 + 时间问候 + 配额） | 中（3–5 天） | 陪伴感的核心，必须有 |
| P2 | 人格特质演化 + 记忆冲突判定 | 中（3–5 天） | 让它"长大"，但要小心人设漂移 |
| P3 | 后台调度（Cloudflare Cron 或本地常驻） | 中 | 主动性需要定时器才能跑 |
